# Linux系统登录监控与自动关机实现方案

## 概述

本文档描述如何通过深度定制Linux系统，实现以下功能：
1. 程序代码随系统启动自动运行
2. 监控终端和SSH登录事件
3. 检测非授权用户名登录
4. 自动发送TCP消息到指定服务器
5. 强制关机

---

## 方案一：PAM模块实现（推荐）

### 优点
- 标准Linux认证框架，兼容性好
- 可以捕获所有登录方式（SSH、本地终端、图形界面）
- 实现相对简单，无需修改内核

---

## 方案二：systemd服务 + 日志监控

### 优点
- 不修改系统核心组件
- 易于维护和调试
- 可以记录详细日志


## 方案四：内核模块（最底层）

### 优点
- 无法被用户空间程序绕过
- 可以监控所有系统调用

### 缺点
- 开发复杂
- 可能导致系统不稳定
- 需要内核开发知识

### 实现思路

使用 LSM (Linux Security Module) 或 hook `execve` 系统调用，监控登录相关的进程启动。

---


## 推荐实施方案

### 最佳实践：PAM模块 + systemd服务双重保障

1. **PAM模块**：作为第一道防线，在认证阶段拦截
2. **systemd服务**：作为监控和日志分析，提供冗余保护
